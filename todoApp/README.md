# Todo App

A responsive todo list built with React + Vite.  with a light/dark mode toggle and layouts for both desktop and mobile.
## Features

- **Add tasks** via the input field or `Enter` key
- **Complete/uncomplete** tasks with a click on the checkbox or task text
- **Delete** individual tasks
- **Filter** by All / Active / Completed
- **Clear Completed** in one click
- **Drag and drop** to reorder tasks (available while the "All" filter is selected)
- **Light / dark mode** toggle, including matching background artwork
- **Responsive layout** — a dedicated mobile layout below 600px, fluid sizing above it

## Tech stack

- [React](https://react.dev/) 18
- [Vite](https://vitejs.dev/) for dev server and bundling
- Plain CSS (no framework) with CSS custom breakpoints
- ESLint (`eslint.config.js`) for linting

## Getting started

```bash
# install dependencies
npm install

# start the dev server
npm run dev

# lint
npm run lint

# build for production
npm run build

# preview the production build
npm run preview
```
