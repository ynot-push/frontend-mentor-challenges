# REST Countries API

A responsive React application that displays information about countries using the REST Countries API (This project was built as a challenge from [Frontend Mentor](https://www.frontendmentor.io/).)

## Features

- View all countries
- Search for a country by name
- Filter countries by region
- View detailed information about a country
- View neighboring countries
- Switch between light and dark themes
- Responsive design for desktop, tablet, and mobile

## Built With

- React
- JavaScript
- Vite
- CSS
- Axios
- REST Countries API
