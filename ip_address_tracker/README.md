# IP Address Tracker

A responsive IP Address Tracker built with React and Vite.

The application allows users to search for an IP address displays information about its location, timezone, and ISP on an interactive map.

## Features

* Search for an IP address or domain
* Display IP address information
* Show geographic location
* Display timezone and ISP
* Interactive map
* Responsive design
* Error handling for invalid searches

## Technologies

* React
* Vite
* JavaScript
* CSS
* REST API
* Leaflet
